# Sculpture meshes: credits and licences

Every `.mvm` file here is a derivative of a third-party 3D scan: merged, cleaned, cropped, decimated, re-oriented and re-scaled. Changes common to all files: floating fragments removed, mesh decimated, smooth vertex normals recomputed, rotated to y up with the front facing +z, base placed on y = 0 and centred on x/z, and scaled to the true height of the work (metres). CC BY credits must stay with the app ("changes were made" as described here).

Format MVM1 (little-endian): `"MVM1"`, uint32 vertexCount, uint32 triangleCount, float32 xyz × V, float32 normal xyz × V, uint32 indices × 3T (CCW seen from outside).

"Objaverse mirror" means the file was downloaded without login from the Objaverse 1.0 dataset (Allen Institute for AI) on Hugging Face, which redistributes Sketchfab models under their original CC licences: `https://huggingface.co/datasets/allenai/objaverse/resolve/main/glbs/<shard>/<uid>.glb`.
